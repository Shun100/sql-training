# トリガー

- 特定のテーブルへの更新処理が行われたタイミングで、指定した関数の呼び出しを定義することができる
- 影響範囲の設定は2種類
  1. 対象テーブルの行ごとの更新に対してトリガーを実行する
  2. SQLごとの更新に対してトリガーを実行する

- 構文
  - 関数の定義
    ``` psql
      CREATE [OR REPLACE] FUNCTION 関数名([引数の型])
        RETURNS [SETOF] 戻り値の型 AS $$ 処理内容 $$ LANGUAGE 使用言語 [引数NULLの挙動] [実行権限]
    ```
  
  - トリガーの定義
    ``` sql
      CREATE TRIGGER トリガー名 タイミング イベント ON テーブル名 [影響範囲] EXECUTE PROCEDURE 関数名([引数]);
    ```
